# claude-statusline-limits

Статуслайн для Claude Code, который заодно кормит лимитами подписки
Vorssaint и другие утилиты, читающие файл истории десктопного Claude.

Такие утилиты берут проценты лимитов только из `plan-usage-history.json`, который ведёт приложение
Claude. Если работаешь только в терминале, цифры там замирают. Claude Code отдаёт статуслайну
`rate_limits`, скрипт дописывает их в тот же файл в формате приложения.

## Что делает

- Печатает строку вида `Opus · 5ч 12% · нед 40%`.
- Дописывает в `~/Library/Application Support/Claude/plan-usage-history.json` замер пятичасового
  и недельного окна. Без изменений пишет не чаще раза в пять минут, хранит месяц истории.
- Пишет под блокировкой и через временный файл, несколько сессий не портят файл.
- Если папки приложения Claude нет, просто рисует статуслайн.

## Установка

```
cp statusline-limits.py ~/.claude/
```

В `~/.claude/settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "python3 ~/.claude/statusline-limits.py"
  }
}
```

macOS, Python 3 без зависимостей.
